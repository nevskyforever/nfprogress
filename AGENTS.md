## О проекте

Это настольное приложение на Python с графическим интерфейсом PySide6 для писателей, чтобы отслеживать прогресс в написании текстов, с игровыми механиками (опционально).

Приложение собирается через Nuitka для:

* Windows;
* macOS Apple Silicon;
* macOS Intel.

## Основные правила работы

* Выполняй только задачу, указанную пользователем.
* Не изменяй несвязанные части проекта.
* Не проводи полный рефакторинг без прямого запроса.
* Перед изменением кода найди связанные файлы и места использования.
* Для поиска по проекту используй `rg`.
* Не изучай весь проект, если задача относится к отдельному модулю.

* Не добавляй новые зависимости без необходимости.
* Не меняй публичное поведение приложения без прямого запроса.

## Локализация

В приложении исходным языком интерфейса и ключей является русский. Поддерживаемые
языки: русский, английский, испанский, немецкий, французский и португальский
(Бразилия).

При добавлении или изменении пользовательского текста обязательно учитывай
локализацию:

* Текст из Python-кода переводи через `localization.tr()`.
* В `QMessageBox` используй `localization.LocalizedMessageBox`: он переводит
  заголовок и сообщение автоматически.
* Методы `NotificationManager.show_success()`, `show_error()`, `show_warning()` и
  `show_info()` также вызывают `tr()` автоматически. Передавай им исходную
  русскую строку, которая присутствует в каталоге.
* Новые подписи, кнопки и другие постоянные элементы интерфейса добавляй в
  соответствующий файл `UI template/*.ui`. Не вноси их вручную в
  сгенерированные файлы `UI_fiiles/*.py`.
* При смене языка открытые формы должны вызывать свой `retranslateUi()`, а
  списки и подписи, заполненные из Python, должны заполняться повторно.
* Пользовательские данные — названия проектов, этапов, собственных наград,
  файлов и введённый пользователем текст — не переводи.

Примеры:

```python
label.setText(tr("Настройки"))
label.setText(tr(f"⭐ Уровень: {level}"))
notifications.show_success("Изменения сохранены")
QMessageBox.warning(parent, "Ошибка", "Сначала выберите проект")
```

Динамическую строку переводи по компонентам, если в неё входит другой
переводимый объект. Обычный перевод шаблона сохраняет динамическое значение как
есть, поэтому такой код может оставить русское название внутри переведённой
строки:

```python
# Неправильно для встроенного предмета: item.name останется русским.
tr(f"Куплено: {item.name}")

# Правильно:
f"{tr('Куплено')}: {localized_game_name(item.name)}"
```

Для игровой части соблюдай следующие правила:

* Не переводи и не изменяй внутренние имена предметов, бафов, категорий,
  статусов и ключей словарей в `game_data.py`, сохранениях и `Qt.UserRole`.
  Игровая логика продолжает работать с каноническими русскими значениями.
* Для отображаемых названий встроенных предметов и бафов используй
  `game_UI.localized_game_name()`. Она отдельно обрабатывает добавленный к имени
  эмодзи.
* Для динамических описаний бафов используй
  `game_UI.localized_game_description()`.
* Для результата применения предмета используй
  `game_UI.localized_item_result()`.
* Переводи отображаемое значение категории отдельно через `tr(category)`, но
  сохраняй исходную категорию в данных элемента списка.

Например:

```python
display_text = (
    f"{localized_game_name(item.name)} x{count} [{tr(category)}]"
)
list_item.setText(display_text)
list_item.setData(Qt.ItemDataRole.UserRole, (category, item_key))
```

Каталог `translations_catalog.py` генерируется автоматически и вручную не
редактируется. Если добавлены новые русские строки:

1. Убедись, что строки находятся в `UI template/*.ui` или в Python-файле,
   перечисленном в `PYTHON_SOURCES` файла `scripts/generate_translations.py`.
2. Если добавлен новый Python-модуль с пользовательскими строками, добавь только
   этот модуль в `PYTHON_SOURCES`.
3. Запусти `python3 scripts/generate_translations.py`. Скрипту нужен интернет,
   и он перегенерирует весь каталог, поэтому внимательно проверь diff и не
   принимай несвязанные ухудшения переводов.
4. Ручные исправления терминов и короткие переводы, которые генератор не может
   корректно собрать из динамической строки, добавляй в
   `TRANSLATION_OVERRIDES` файла `localization.py` для всех пяти нерусских
   языков.

После изменений локализации запусти как минимум:

```bash
python3 -m py_compile localization.py <изменённые Python-файлы>
python3 -m pytest -q tests/test_localization.py
```

Проверь, что новый текст переводится на всех пяти языках, динамические значения
сохраняются, а внутренние ключи игровых объектов не изменились. Для всех
нерусских языков пользовательское соглашение намеренно показывается в одной
английской версии.

* Не запускай одновременно сборки для всех платформ, если задача этого не требует.
* При изменении сборочных скриптов проверяй различия между Windows, macOS ARM и macOS Intel.
* Не изменяй пути публикации, SSH-настройки, ключи и данные сервера без прямого запроса.
